⏱ Widget « Mes chronos »

À installer une seule fois sur ton iPhone (3 minutes). Les mises à jour suivantes sont automatiques.

  1. Installe l'app ScriptableGratuite, sur l'App Store. Ouvrir l'App Store
  2. Copie le scriptUn seul bouton, rien à taper.
  3. Colle-le dans ScriptableOuvre Scriptable, touche + en haut à droite, appuie dans la page blanche et choisis « Coller ». Renomme le script « Oxybol chronos » (touche son titre en haut), puis touche ▶ pour le lancer une fois.
  4. Ajoute le widgetÉcran d'accueil : appui long sur un fond libre → + → Scriptable → choisis une taille → « Ajouter ». Touche le widget → Script : « Oxybol chronos ».
